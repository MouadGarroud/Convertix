# 📄 Convertix

**Convertix** is a lightweight, intuitive tool that allows you to convert between **DOCX and PDF** formats with a single click. Built with a beautiful GUI using Tkinter and powered by `docx2pdf` and `pdf2docx`, it’s the perfect tool for students, professionals, and anyone dealing with documents.

---

## 🧠 Project Overview

Convertix is designed to simplify the conversion of Microsoft Word documents to PDFs and vice versa. Whether you're sending a resume, preparing a report, or just need a quick format change — Convertix does it cleanly and instantly.

---

## ⚙️ Features

- 🔄 **Convert DOCX to PDF** using Microsoft Word (Windows only)
- 🔁 **Convert PDF to DOCX** using `pdf2docx`
- 💼 Professional GUI with status updates and a progress bar
- 📁 Auto-saves in the same folder with the same base filename
- 🖼️ Custom icon and branding (supports `.ico`)
- 🧵 Smooth performance via multithreading

---

## 🧩 Modules Used

- `tkinter` – GUI framework
- `docx2pdf` – For DOCX ➡ PDF conversion (requires MS Word)
- `pdf2docx` – For PDF ➡ DOCX conversion
- `threading` – Keeps the app responsive
- `os`, `sys` – Path handling & PyInstaller compatibility
